3. Heuristic Search & 8-Puzzle Concepts

The A* Search Algorithm

A* evaluates states using the function: f(n) = g(n) + h(n), where:

  • g(n): The exact path cost from the start configuration to node $n$.
  • h(n): The heuristic estimate of the remaining cost from $n$ to the goal.
  • f(n): The estimated total cost of the cheapest solution passing through $n$.

Admissible Heuristics

  • Misplaced Tiles: Counts the number of non-blank tiles not in their goal position. Admissible because each misplaced tile requires at least 1 move.
  • Manhattan Distance: Computes $\sum |r - r_{goal}| + |c - c_{goal}|$ across all non-blank tiles. Strictly dominates Misplaced Tiles because every misplaced tile contributes $\ge 1$, and more distant tiles contribute higher values without overestimating.

Inversion Parity Solvability Invariant

For a 3x3 board, an inversion is a pair of tiles $(a, b)$ where $a$ appears before $b$ in row-major order, but $a > b$. Horizontal blank slides do not change tile order; vertical slides alter inversions by $+2$, $-2$, or $0$. Therefore, the parity (even/odd) of the inversion count is an invariant. Because the standard goal state has 0 inversions (EVEN), any puzzle with an ODD inversion count is mathematically proven to be unsolvable and is rejected before search starts.

4. Constraint Satisfaction & Sudoku Concepts

CSP Formulation: ⟨X, D, C⟩

  • Variables (X): 16 (for 4x4) or 81 (for 9x9) cell variables $X_{r, c}$.
  • Domains (D): Allowed numbers $\{1..N\}$ for empty cells; $\{d\}$ for initial clues.
  • Constraints (C): All-Different relations across each row, column, and subgrid, modeled as binary inequality arcs $(X_i \ne X_j)$ between peer cells.

The 4 Solving Algorithms

  1. Plain Backtracking: Baseline Depth-First Search with row-major variable selection and ascending value assignment.
  2. Backtracking + MRV (Minimum Remaining Values): The *"fail-first"* heuristic. Selects the unassigned cell with the smallest domain size, triggering conflicts near the top of the search tree rather than deep in dead-end branches.
  3. Forward Checking: Whenever a variable receives a value, that value is immediately pruned from the domains of all unassigned peers. If any peer domain is wiped out to size 0, the branch fails immediately.
  4. AC-3 (Arc Consistency Algorithm 3): Propagates constraints across directed arcs. If variable $X_j$ has only one possible value $\{y\}$, then $y$ is removed from $X_i$'s domain. If $X_i$'s domain shrinks, AC-3 propagates this revision backwards to all variables constraining $X_i$.

5. Theoretical Comparison: Search vs. CSP

Comparison Dimension State-Space Search (8-Puzzle) Constraint Satisfaction (Sudoku)
Primary Objective Find an optimal sequence of actions (path). Find a valid complete assignment of variables.
State Representation Atomic board configuration tuple. Factored variables with discrete domain sets.
Transitions / Moves Tile slides (Up, Down, Left, Right). Order matters. Variable assignment. Order has no physical cost.
Path Cost Crucial ($g(n)$ accumulated moves). Irrelevant (only final consistency matters).
Search Strategy Best-First Search (A* with priority queue). Depth-First Backtracking + Domain Propagation.
Heuristic Role Guides search towards goal ($h(n)$ distance). Prunes branching factor (MRV, LCV).
Optimality Guaranteed minimum moves if $h$ is admissible. Feasibility (any valid board satisfies constraints).
Practical Applications GPS route planning, robotics, gaming AI. Scheduling, timetabling, circuit placement, resource allocation.
